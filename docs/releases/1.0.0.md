# Jarvis 1.0.0

Независимый кастомный релиз прошивки и веб-панели «Камин и Стекло» для Яндекс Станции Лайт 2 (`Georgvadis/Jarvis`):

- **Независимые обновления и отвязка от апстрима (`Georgvadis/Jarvis`)**:
  - Все OTA-проверки, каталог официальных плагинов и ссылки обновлений переведены на репозиторий `Georgvadis/Jarvis`; ночное автообновление по умолчанию отключено (`update_auto: false`, `no_stats: true`), а старые привязки к `newfpv/YaJarvis` автоматически мигрируются при старте.
- **Переключение профилей ассистента голосом (`switch_profile`)**:
  - Поддержка мгновенных команд без обращения к модели («переключи профиль на Рюка», «включи ассистента Аянами») и инструмента `switch_profile` / `switch_assistant` с падежами, обновлением подсветки и мягким завершением диалога после подтверждения.
- **Восприятие речи и ускорение отклика (`lite2fix46`)**:
  - Хэндофф последних `200 мс` preroll для `classic`, звуковой отклик `wake_ack_chime`, фоновый прогрев кэша `wake-replies`, быстрый дакинг YouTube Music / Яндекс Музыки / фона.
  - Адаптивный `Capture` с предзаписью и тихими порогами VAD по умолчанию (`vad_threshold: 380`, `vad_silence_ms: 850`), склейка прерванных паузами фраз, отсев голого слова активации, прямой `/stt` без Lua/Base64 и быстрые локальные команды (время/дата, громкость, звуки сна, погода).
  - Выборочное подключение `web_search` / `googleSearch`, фоновый прогрев `"codex.warm"` для `Classic` ChatGPT, раннее расщепление фраз и прямой HTTP/2-стриминг `fish-audio-tts`.
- **Дизайн веб-панели («Камин и Стекло»), YouTube Music, умные инструменты и память**:
  - Включены все доработки `lite2fix1`–`lite2fix45`: переработанный UI (`Home`, `Studio`, `Charts`, `Settings`, светлая/тёмная темы, PWA), поиск официальных треков и лайки в YouTube Music + тихая Яндекс Музыка, постоянная память диалога, локальный AI-DJ, читалка книг, игры и 6 нативных инструментов управления колонкой.
